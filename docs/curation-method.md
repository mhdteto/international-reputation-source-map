# Curation method

Select a source because it can help answer a defined identity/evidence question, not because it has a prestigious domain or might host a promotional link.

## Entry criteria

1. An official publisher or documented primary service is identifiable.
2. Its scope is relevant to a specific class of claims.
3. A primary reference supports the description of the service.
4. Coverage and evidential limits are recorded.
5. Access and verification uncertainty are visible.

The initial selection deliberately begins with official registers, filings and research infrastructure. It does not claim to be an exhaustive source strategy for every executive, industry or jurisdiction. Relevant independent journalism, professional institutions and original publications may also matter in a real engagement; add them only after a claim-specific review.

## Verification labels

- **Official page read:** a relevant official page was read during curation. This does not mean every linked database function or record was tested.
- **Official link confirmed:** an official explanation/partner page identifies and links the destination. Record-level access was not established.
- **Official indexed description:** an official description was visible in the search index; direct reading was blocked or incomplete. Availability and functionality remain unconfirmed.

A later builder run validates the CSV structure, not the continued availability or truth of an external site. A date on a row is a research date, not a current health check.

## Maintenance

Preserve source IDs when updating an entry. Document changed scope, links and access limits in the changelog. Revisit blocked or changed destinations through ordinary official channels; do not bypass access restrictions. Remove or qualify an entry if its primary basis cannot be established.
