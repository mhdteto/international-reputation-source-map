# v1.0.0 — stable public release

Published for the first time as a versioned GitHub release. The tag identifies the tested code, documentation, examples and contribution forms. The CLI and existing output formats are unchanged by the navigation and connected-workflow additions.

## Included

- Existing Python standard-library tool, documentation and transparent interpretation limits.
- Curated public-source catalogue and deterministic sample reports; CI on Python 3.10 and 3.13.
- Start-here navigation, task-specific next step and issue forms for bugs, features and source/methodology proposals.
- A 16-entry source catalogue with explicit scope, access and verification labels; not a record-level verification result.

## Download and use

Download the Source code ZIP or tar.gz attached automatically by GitHub. Extract it, open its README and run its Quick start command. Python 3.10+; no third-party packages or API keys.

[Complete fictional workflow](https://github.com/mhdteto/authority-architecture-system/tree/main/examples/fictional-workflow) · [Report an issue](https://github.com/mhdteto/international-reputation-source-map/issues/new/choose)

## Boundaries

No guaranteed ranking, citation, recommendation, factual verdict or universal authority score. The tool works offline on supplied inputs.
