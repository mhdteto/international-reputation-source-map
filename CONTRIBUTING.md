# Contributing

Propose a source with its official destination, primary explanatory reference, claim-specific scope, coverage exclusions, access note, verification level and checked date. Do not submit promotional directory lists, guarantees, speculative allegations or private personal records.

Run `python3 -m unittest discover -s tests` and regenerate the catalogue with the documented command. New or changed external sources need human primary-source review; the compiler does not verify them. Original curation notes/docs/artwork use CC BY 4.0; code/tests use MIT. Third-party material keeps its own rights.

## Choose a contribution route

- [Bug or documentation error](https://github.com/mhdteto/international-reputation-source-map/issues/new?template=bug_report.yml): include a release tag or commit and a minimal public/fictional reproducer.
- [Feature request](https://github.com/mhdteto/international-reputation-source-map/issues/new?template=feature_request.yml): state the task, example and proposed behavior.
- [Source or methodology proposal](https://github.com/mhdteto/international-reputation-source-map/issues/new?template=source_proposal.yml): provide the specific claim, publisher, dates, market, relationship and limits.

Run the documented validation and preserve the distinction between observed, supplied, inferred and unknown. See the [connected fictional workflow](https://github.com/mhdteto/authority-architecture-system/tree/main/examples/fictional-workflow) for an example.
